## ✨ Características Principales

- ✅ **Diseño 100% Responsive** - Adaptable a móviles, tablets y escritorio.
- ✅ **Single Page Application (SPA)** - Navegación rápida y fluida sin recargar la página.
- ✅ **Optimización SEO** - Meta tags configuradas para compartir el enlace correctamente en redes sociales.
- ✅ **Sección de Proyectos** - Galería interactiva mostrando mi stack y repositorios.

## Tecnologías

Como este proyecto es un portafolio estático, el enfoque está 100% en el rendimiento y diseño del Frontend:

| Tecnología | Uso principal |
| :--- | :--- |
| **React.js** | Creación de componentes UI y manejo del estado |
| **JavaScript (ES6+)** | Lógica de interactividad y animaciones |
| **HTML5 & CSS3** | Estructura semántica y diseño visual a medida |
| **Vite** | Empaquetador (Build tool) para máxima velocidad |
| **GitHub Pages**| Despliegue (Deploy) continuo y alojamiento |

## 🚀 Instalación Local

Si querés correr el código de mi portafolio en tu máquina local:

```bash
# 1. Clonar el repositorio
git clone [https://github.com/MontiNahuel/portafolioV6.git](https://github.com/MontiNahuel/portafolioV6.git)

# 2. Entrar a la carpeta
cd portafolioV6

# 3. Instalar dependencias
npm install

# 4. Iniciar el servidor de desarrollo
npm run dev
